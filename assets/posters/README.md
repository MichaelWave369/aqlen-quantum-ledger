## Asset rule

A poster image should not be treated as a scientific source. It is a communication artifact.

Every claim on a poster must be traceable to either:

1. an evidence anchor,
2. a source-status field,
3. a claim-boundary note, or
4. a clearly labeled concept/design statement.
