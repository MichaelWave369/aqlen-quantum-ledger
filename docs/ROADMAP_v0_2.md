# AQLEN v0.2 Roadmap

## Goal

Turn v0.1 from a static scaffold into a living evidence-intake and dashboard prototype.

## v0.2 targets

1. Evidence intake pipeline
2. Registry validation
3. Readiness dashboard prototype
4. Separate silicon platform lanes
5. Productization path

## Initial dashboard panels

- Evidence Anchors
- Qubit Provenance Receipts
- Noise-Origin Events
- Calibration Drift Receipts
- Readiness Score
- Claim Boundary Warnings

## Done definition

- Evidence files validate locally.
- Sample receipts load cleanly.
- Readiness scorer reproduces the sample score.
- Dashboard can load evidence anchors and sample data.
- README keeps the public claim language grounded.
